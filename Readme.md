# Microsoft Rewards Bot

## Descrição

Bot feito como parte de estudo sobre automação de tarefas. Realiza pesquisas no edge de forma automática para obter prêmios no programa de recompensas da Microsoft. 

## Tecnologias

**Linguagem**: Python
**Automação**: PyAutoGUI
**Leitura de arquivos**: Pandas
**Gerenciador de Pacotes**: UV

## Como usar

Instalar e rodar o executável da [release mais recente](https://github.com/daviguarisa/msrbot/releases).
Para interromper a execução arraste o mouse para o canto superior esquerdo.
